# Sicurezza

## Segnalare una vulnerabilità

Non aprite una issue pubblica. Usate la segnalazione privata di GitHub (**Security → Report a vulnerability** in questo repository) oppure scrivete a <info@tumas.net>.

Indicate:

- la versione (`hw-hub version`, o il commit);
- i passi per riprodurre il problema;
- l'effetto che avete osservato.

Confermiamo la ricezione e concordiamo con chi segnala la data di pubblicazione, dopo che la correzione è disponibile.

## Versioni supportate

Ricevono correzioni di sicurezza l'ultima versione rilasciata e il ramo `main`.

## Verificare ciò che installate

Ogni rilascio è firmato con Sigstore e ha un'attestazione di provenienza di GitHub. Come verificarli: [docs/installazione.md](docs/installazione.md#verificare-un-rilascio).
